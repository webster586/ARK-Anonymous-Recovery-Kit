RETROARCH · EINRICHTUNG UND BEDIENUNG

    
    
     
  1. Cores laden: RetroArch öffnen → Hauptmenü → Online-Aktualisierung → Core-Downloader → je System den passenden Core herunterladen (einmalig Internet nötig).
    2. 
     
  2. ROM-Verzeichnis einstellen: Einstellungen → Verzeichnisse → Startverzeichnis auf die ROM-Sammlung zeigen (z. B. I:\Media\Spiele\Batocera_Backup\roms).
    3. 
     
  3. Verzeichnis scannen: Hauptmenü → Importieren → Verzeichnis scannen → den ROM-Ordner wählen → RetroArch erkennt Systeme und Cores automatisch.
    4. 
     
  4. Spielen: Nach dem Scan erscheinen alle erkannten Spiele direkt im RetroArch-Hauptmenü als Liste ("Verlauf" bzw. eigene Sammlung) – einfach anklicken und starten.
    5. 
    

    Für manche Systeme (z. B. PSX, PS2) wird zusätzlich eine BIOS-Datei im System-Verzeichnis benötigt (Einstellungen → Verzeichnisse → System/BIOS). RetroArch verwaltet ROMs, Cores und Speicherstände komplett selbst; ARK startet das Programm nur.
